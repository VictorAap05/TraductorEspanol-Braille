      Hook de adaptación bidireccional para el traductor Braille.

      • Modo 'espanol-braille': usuario escribe texto, ve celdas Braille.
      • Modo 'braille-espanol': usuario hace clic en letras del teclado Braille, el panel izquierdo muestra las celdas Braille acumuladas y el panel derecho muestra el texto resultante en español.
